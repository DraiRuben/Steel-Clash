# Steel Clash

## Context of the game's creation :
This game is a school project were we had to create a Fighting game in 1 weeks, we where two student programmers for this project, all the documents who were created in the process are in a [Google Drive](https://drive.google.com/drive/folders/1BwQOexeqKriAx6YWdt1yJCGG_8yERpZ2?usp=sharing).

## Controls :

### Camera mouvements :
- No camera mouvement possible

### Player actions (in level) :
| Action                                                    | Input (AZERTY)                                                      | Input (QWERTY)                                                      |
|-----------------------------------------------------------|---------------------------------------------------------------------|---------------------------------------------------------------------|
| Aiming upwards                                            | Z, Left joystick up                                                 | W, Left joystick up                                                 |
| Move left                                                 | Q, Left joystick left                                               | A, Left joystick left                                               |
| Fall faster, Aiming downwards                             | S, Left joystick right                                              | S, Left joystick right                                              |
| Move left                                                 | D, Left joystick down                                               | D, Left joystick down                                               |
| Jump, Double jump                                         | Space bar, South button gamepad, North button gamepad               | Space bar, South button gamepad, North button gamepad               |
| Basic attack                                              | J, West button gamepad                                              | J, West button gamepad                                              |
| Special attack                                            | K, Est button gamepad                                               | K, Est button gamepad                                               |
| Counter                                                   | L, Left trigger (LT), Right trigger (RT)                            | L, Left trigger (LT), Right trigger (RT)                            |
| Pause/unpause the game                                    | Escape, Start, Select                                               | Escape, Start, Select                                               |

### Player actions (for UIs) :
| Action                                                    | Input (AZERTY)                                                      | Input (QWERTY)                                                      |
|-----------------------------------------------------------|---------------------------------------------------------------------|---------------------------------------------------------------------|
| Interact with buttons                                     | Mouse left click, Enter, South button gamepad                       | Mouse left click, Enter, South button gamepad                       |
| Move up                                                   | Z, Left joystick up                                                 | W, Left joystick up                                                 |
| Move left                                                 | Q, Left joystick left                                               | A, Left joystick left                                               |
| Move down                                                 | S, Left joystick right                                              | S, Left joystick right                                              |
| Move right                                                | D, Left joystick down                                               | D, Left joystick down                                               |
